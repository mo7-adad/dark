## Features

- Right-to-left Arabic layout
- Hero, stats, properties, about, services, prices, FAQ and contact sections
- Responsive design with Flexbox and media queries

## Project Structure

```
dark/
├── index.html
└── style.css
```

## Run Locally

```bash
git clone https://github.com/mo7-adad/dark.git
cd dark
```

Then open `index.html` in your browser, or right-click it in VS Code and choose **Open with Live Server**.
